Process key

    Diagram controls

    Data

    Measured against each flow's own parent, not the root.

    Keeps only the largest contributors, the way openLCA's own Sankey does. 0 keeps everything.

    Typography

    Annotations — including any label you detach from a node — can be dragged and retyped directly on the diagram.

    Labels

    Silences labels on hairline nodes without removing them from the diagram — the data is untouched.

    Turns every node label about the point where it meets its node. ±90° stands them upright, which is what a narrow column wants; the canvas grows to make room. Also applied to the exported PNG and SVG.

    Click any node on the diagram to rename it, recolour it, or detach its label as a free-floating, draggable annotation.

    Colours

    Layout

    Drag nodes on the diagram to move them; the positions stick until you reset them.

    Selected node

    Click a node on the diagram to edit it.

    A detached label becomes an annotation you can drag anywhere and retype in place — and it can carry its own size.

    Export & settings

    The preset switches to the print palette on a white ground with black text, and numbers the nodes with a key below the diagram.

    Changes are remembered in this browser.
